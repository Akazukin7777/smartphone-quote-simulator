# 光回線見積もりツール

ドコモ光、@nifty光、SoftBank 光の1ギガタイプについて、会社選択、申込区分選択、オプション選択、見積もり結果の順にページを切り替えながら進めるブラウザ用の見積もりツールです。

## 使い方

`index.html` をブラウザで開くと利用できます。選択内容はブラウザのローカルストレージに保存され、最後の `result.html` で保存済みデータから見積額を計算します。

## 料金データの更新

- `data/plans.json`: メンテナンス用の料金データベース
- `data/plans.js`: ブラウザ表示用データ
- `scripts/build-plan-js.mjs`: `plans.json` から `plans.js` を再生成
- `scripts/check-plan-sources.mjs`: 公式ページに登録済みの金額文字列が残っているか確認

金額を変える場合は、基本的に `data/plans.json` の該当プロバイダだけを修正し、次のコマンドでブラウザ用データを更新します。

```bash
node scripts/build-plan-js.mjs
```

公式ページの表記確認を行う場合:

```bash
node scripts/check-plan-sources.mjs
```

## 計算内容

- 初期費用: 契約/回線手数料 + 回線工事費 + 光電話初期費用 + 光テレビ初期費用 + その他初期費用
- 事業者変更の場合、移転元の事業者変更手数料を最大目安3,300円として初期費用に加算
- 月額ランニングコスト: 回線月額 + 固定電話オプション + 光テレビ + その他月額費用
- @nifty光は2年プラン(N)と3年プラン(N)を選択可能。3年プラン(N)はノジマ BB挑戦パックの新規/事業者変更の段階月額を反映
- 光電話は、新規発番、番号引き継ぎ、事業者変更で引き継ぎの初期費用パターンを選択可能
- SoftBank 光は、光電話（N）基本プランとBBフォンを選択可能。通常オプションとおうち割指定オプションを切り替えでき、BBフォンは通常513円/月、おうち割指定オプションでは550円/月として登録
- @nifty光のみ、初期加入オプション（@nifty 優待サービス、@nifty セキュアプライバシー、@niftyまかせて365）の合計1,540円を初期費用に加算
- 加入電話番号を光電話へ引き継ぐ場合、NTT東日本/NTT西日本から利用休止工事費などが別途請求される場合があります。
- 工事費の分割払いは月額ランニングコストに含めず、見積もり結果の補足として表示します。
