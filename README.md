# スマホ見積もりシミュレーター

現在の利用状況、機種変更、MNPの3カラムでスマホ料金を比較できるブラウザアプリです。

## 使い方

`index.html` をブラウザで開くと利用できます。入力内容はブラウザのローカルストレージに保存されます。

## 計算内容

- 現在の利用状況: 基本料金 + 端末料金
- 機種変更 / MNP: 基本料金 + 端末分割金 + 補償
- ネット割 / 家族割: チェックすると月額から割引
- Y!mobile シンプル3の家族割: 1回線目は割引なし、2回線目以降のみ割引
- 実質負担調整: キャッシュバック等の月額マイナス額と対象月数から実質負担を表示
- 一括払いの場合: 端末一括料金は初期・一括費用に加算
- 分割払いの場合: 1〜24ヶ月目と25〜48ヶ月目の月額を別々に表示
- プログラム利用料: 月額換算せず、返却時費用として一度だけ加算
- 25〜48ヶ月目: 返却時は端末分割金を支払免除として計算

## 料金プランデータ

- `data/plans.json`: 公式ページを確認して登録した料金プランDB
- `data/plans.js`: ブラウザ表示用の軽量データ（`plans.json` から生成）
- `scripts/check-plan-sources.mjs`: 公式ページ上に登録済みのプラン名・金額文字列が残っているか確認する簡易チェック
- `scripts/build-plan-js.mjs`: `plans.json` から `plans.js` を再生成

確認コマンド:

```bash
node scripts/build-plan-js.mjs
node scripts/check-plan-sources.mjs
```
